[그림 단어장 사이트 - 사용 설명서]

■ 구성
- word-app.html    : 학생이 실제로 쓰는 화면 (단어 목록 + 자동재생)
                      ※ 예전엔 index.html이었는데, 학생마다 링크가 달라야 해서
                        이름을 바꿨습니다. (index.html은 기존 학생관리 사이트가
                        쓰고 있어서 겹치면 안 되기도 하고요)
- admin.html       : 선생님용 "학생 링크 관리" 화면 (비밀번호 필요)
- firebase-shared.js : 학생 정보를 불러오기 위한 Firebase 연동 설정
- style.css        : word-app.html 디자인
- app.js           : word-app.html 동작 로직
- words.json       : 1029개 단어 목록/순서
- hotspots.json    : 카드 그림 위 터치 영역 좌표 (파란 단어 / 나팔+첫 줄 / 빨간 단어 / 그림 위치)
                      ※ 이미지 분석(OCR)으로 자동 생성한 파일이라 없어도 앱은 동작하지만,
                        그러면 카드 터치 기능(다시 듣기, 빨간 단어)만 빠집니다.
- assets/img/      : 재생 화면용 큰 카드 이미지 (단어+뜻풀이+그림)
- assets/thumb/    : 목록 화면용 작은 미리보기 이미지
- assets/audio/    : 단어 발음(_w.mp3), 영영풀이(_d.mp3)
- assets/ani/      : 원본 CD의 애니메이션을 영상(mp4, 소리 포함)으로 바꾼 것. 788개 단어, 최대 8초
- assets/sfx/      : 효과음만 있는 단어(241개)의 효과음 mp3. 최대 5초로 잘라 둠
- motion.json      : 단어별 움직임 정보 (v = 애니메이션 영상, s = 효과음만). 없으면 예전 방식

■ 업로드 방법
1. 이 폴더(word-app) 전체를 "폴더째로" 업로드하세요. (모든 하위 폴더 포함)
   ⚠ 기존 사이트와 같은 저장소/서버에 올릴 때는 반드시 word-app 폴더 안에 넣어야 해요.
     기존 사이트에도 admin.html, words.json이 있어서, 폴더 없이 같은 위치에 올리면
     서로 덮어써서 양쪽 다 망가집니다.
   파일들 간의 상대 경로가 그대로 유지되어야 합니다. (구조를 바꾸면 안 됨)
2. 주소창에 word-app.html을 직접 입력해서 접속합니다.
   예) https://내도메인.com/word-app/word-app.html
   (이 폴더에는 더 이상 index.html이 없어요. 같은 서버에 기존 학생관리
    사이트의 index.html이 따로 있어도 서로 겹치지 않습니다.)

■ 학생 링크 관리 (새 기능)
1. admin.html에 접속해서 비밀번호(bookquiz2024)를 입력하면 학생 목록이 보여요.
   (비밀번호를 바꾸고 싶으면 admin.html 안의 ADMIN_PASSWORD 값을 수정하세요)
2. 이 목록은 기존에 운영 중이던 학생/가족 관리 사이트(index.html)와 같은
   Firebase 프로젝트("students" 컬렉션)를 그대로 불러옵니다. 그래서 그
   사이트에 등록해 둔 학생 정보가 자동으로 여기 나타나요. 따로 학생을
   또 입력할 필요가 없습니다.
3. 형제자매가 있는 가족은 이름 옆에 "+" 버튼이 보여요. 눌러서 펼치면
   형제자매 목록이 나오고, 각자 "링크 복사" 버튼으로 그 학생만의 전용
   링크를 복사할 수 있어요. (예: word-app.html?student=학생아이디)
4. 만약 학생 데이터가 다른 Firebase 프로젝트에 있다면, firebase-shared.js
   안의 firebaseConfig 값을 그 프로젝트 설정으로 바꿔주세요.

■ word-app.html 동작 방식
1. admin.html에서 복사한 링크(?student=아이디가 붙은 주소)로 들어가면
   상단에 "OO 학생, 안녕하세요!"처럼 이름이 표시됩니다. (링크 없이
   그냥 word-app.html로 들어가면 이름 표시 없이 그대로 사용 가능)
2. 목록 화면에서 원하는 단어 카드를 터치하면 재생 화면으로 이동하고,
   동시에 전체화면 + 가로모드가 됩니다. (안드로이드 크롬 기준.
   아이폰은 브라우저 제한으로 전체화면/가로 고정이 안 될 수 있어요.)
3. 기본은 "수동" 방식입니다.
   단어 발음 재생 → (0.8초 뒤) 그림이 움직이며 효과음 재생 → (1초 뒤) 영영풀이 재생 →
   전부 끝나면 "다음" 버튼이 활성화됩니다. 다음 버튼을 눌러야 다음 단어로 넘어가요.
   (움직임이 없는 단어는 예전처럼 단어 → 약 3초 → 영영풀이)
   - 애니메이션이 있는 단어(788개): 원본 CD의 애니메이션이 소리와 함께 재생됩니다.
   - 효과음만 있는 단어(241개): 효과음이 나오는 동안 그림 둘레가 콩닥콩닥 표시됩니다.
   - 그림 부분을 터치하면 움직임+효과음이 다시 재생됩니다. (재생 도중에도 가능)
   - 다음 버튼은 언제나 "목록 순서상 다음 단어"로 갑니다.
   - 이전 버튼은 "방금 전에 보던 카드"로 돌아갑니다. 빨간 단어 팝업으로 A→B→C로
     넘어갔다면 이전을 누를 때마다 C→B→A 순서로 되돌아가요. (최대 50개까지 기억,
     기록이 없으면 목록 순서상 바로 앞 단어로 갑니다. 돌아간 카드는 단어와 영영풀이를
     처음부터 다시 읽어줍니다.)
4. 화면 위쪽 "▶ 자동재생" 버튼을 누르면 예전 방식으로 바뀝니다.
   (영영풀이가 끝나고 약 1.2초 뒤 자동으로 다음 단어로 이동, 마지막 다음엔 처음으로 반복)
   "■ 자동재생 끄기"를 누르면 다시 수동으로 돌아갑니다.
5. 카드를 직접 터치할 수 있어요.
   - 파란 단어(메인 단어)를 터치 → 단어를 다시 읽어줍니다.
   - 나팔 그림 또는 영영풀이 첫 줄을 터치 → 영영풀이를 다시 읽어줍니다.
     (읽는 도중에 눌러도, 다 끝난 뒤에 눌러도 다시 읽어줘요)
   - 빨간 단어를 터치 → 그 단어를 읽어주고, 그 단어가 메인인 카드의 그림이
     작은 팝업으로 뜹니다. 팝업 그림을 터치하면 그 단어 화면으로 이동해요.
     (bat, fly, light처럼 뜻이 여러 개인 단어는 문장의 뜻에 맞는 그림 한 장만 뜹니다.
      뜻 선택은 문장을 읽고 하나씩 정해서 hotspots.json에 저장해 둔 것입니다.)
     * 카드에 있는 단어는 녹음된 발음, horns·women처럼 모양이 바뀐 단어나
       카드가 없는 단어는 브라우저 음성(TTS)으로 화면에 보이는 그대로 읽어줍니다.
   - 빨간 단어를 눌러서 읽는 도중이었더라도, 다 읽고 나면 원래 진행하던
     단어/영영풀이 읽기를 이어서 끝냅니다.
6. 화면 위쪽 "← 목록" 버튼 또는 기기의 뒤로가기 버튼을 누르면 전체화면이 풀리고
   목록 화면으로 돌아갑니다.
7. 검색창에 단어를 입력하면 해당 단어만 찾아볼 수 있습니다.
   상단의 알파벳 버튼을 누르면 그 글자로 시작하는 목록으로 바로 이동합니다.

■ 참고
- hotspots.json은 카드 이미지를 자동 분석해서 만들었기 때문에, 아주 드물게 빨간 단어의
  위치나 연결된 그림이 어긋날 수 있어요. 발견되면 알려주세요.

[그림 단어장 사이트 - 사용 설명서]

■ 구성
- word-app.html    : 학생이 실제로 쓰는 화면 (단어 목록 + 자동재생)
                      ※ 예전엔 index.html이었는데, 학생마다 링크가 달라야 해서
                        이름을 바꿨습니다. (index.html은 기존 학생관리 사이트가
                        쓰고 있어서 겹치면 안 되기도 하고요)
- admin.html       : 선생님용 "학생 링크 관리" 화면 (비밀번호 필요)
- firebase-shared.js : 학생 정보를 불러오기 위한 Firebase 연동 설정
- style.css        : word-app.html 디자인
- app.js           : word-app.html 동작 로직
- words.json       : 1029개 단어 목록/순서
- assets/img/      : 재생 화면용 큰 카드 이미지 (단어+뜻풀이+그림)
- assets/thumb/    : 목록 화면용 작은 미리보기 이미지
- assets/audio/    : 단어 발음(_w.mp3), 영영풀이(_d.mp3)

■ 업로드 방법
1. 이 폴더(word-app) 전체를 "폴더째로" 업로드하세요. (모든 하위 폴더 포함)
   ⚠ 기존 사이트와 같은 저장소/서버에 올릴 때는 반드시 word-app 폴더 안에 넣어야 해요.
     기존 사이트에도 admin.html, words.json이 있어서, 폴더 없이 같은 위치에 올리면
     서로 덮어써서 양쪽 다 망가집니다.
   파일들 간의 상대 경로가 그대로 유지되어야 합니다. (구조를 바꾸면 안 됨)
2. 주소창에 word-app.html을 직접 입력해서 접속합니다.
   예) https://내도메인.com/word-app/word-app.html
   (이 폴더에는 더 이상 index.html이 없어요. 같은 서버에 기존 학생관리
    사이트의 index.html이 따로 있어도 서로 겹치지 않습니다.)

■ 학생 링크 관리 (새 기능)
1. admin.html에 접속해서 비밀번호(bookquiz2024)를 입력하면 학생 목록이 보여요.
   (비밀번호를 바꾸고 싶으면 admin.html 안의 ADMIN_PASSWORD 값을 수정하세요)
2. 이 목록은 기존에 운영 중이던 학생/가족 관리 사이트(index.html)와 같은
   Firebase 프로젝트("students" 컬렉션)를 그대로 불러옵니다. 그래서 그
   사이트에 등록해 둔 학생 정보가 자동으로 여기 나타나요. 따로 학생을
   또 입력할 필요가 없습니다.
3. 형제자매가 있는 가족은 이름 옆에 "+" 버튼이 보여요. 눌러서 펼치면
   형제자매 목록이 나오고, 각자 "링크 복사" 버튼으로 그 학생만의 전용
   링크를 복사할 수 있어요. (예: word-app.html?student=학생아이디)
4. 만약 학생 데이터가 다른 Firebase 프로젝트에 있다면, firebase-shared.js
   안의 firebaseConfig 값을 그 프로젝트 설정으로 바꿔주세요.

■ word-app.html 동작 방식
1. admin.html에서 복사한 링크(?student=아이디가 붙은 주소)로 들어가면
   상단에 "OO 학생, 안녕하세요!"처럼 이름이 표시됩니다. (링크 없이
   그냥 word-app.html로 들어가면 이름 표시 없이 그대로 사용 가능)
2. 목록 화면에서 원하는 단어 카드를 터치하면 재생 화면으로 이동합니다.
3. 단어 발음(0W) 재생 → 약 3초 대기 → 영영풀이(1D) 재생 → 약 1.2초 대기 →
   다음 단어로 자동 이동. 마지막 단어까지 가면 처음 단어로 돌아가 계속 반복됩니다.
4. 화면 상단 "← 목록으로" 버튼 또는 브라우저/기기의 뒤로가기 버튼을 누르면
   자동재생이 멈추고 목록 화면으로 돌아갑니다.
5. "일시정지" 버튼으로 재생을 잠깐 멈췄다가 다시 이어갈 수 있습니다.
6. 검색창에 단어를 입력하면 해당 단어만 찾아볼 수 있습니다.
   상단의 알파벳 버튼을 누르면 그 글자로 시작하는 목록으로 바로 이동합니다.

■ 참고 (다음 단계로 남겨둔 기능)
- 카드 그림 속 빨간색 단어(animal, horns 등)를 터치해서 작은 팝업으로
  그 단어의 그림+발음을 보여주는 기능은 이번 버전에 포함되지 않았습니다.
  (어떤 빨간 단어가 어느 폴더와 연결되는지 알려주는 데이터가 없어서,
  다음 단계에서 이미지 분석(OCR)으로 자동 매칭 작업이 필요합니다.)

■ 단어 수
